# Azure Hotel

Full-stack web application for hotel reservation management, developed as a university project at the Faculty of Organizational Sciences, University of Belgrade.

The application supports different user roles and covers the complete reservation process, from guest registration and room booking to reservation processing and invoice generation.

## Key Features

- Guest registration and email verification
- JWT-based authentication and role-based authorization
- Room browsing and filtering
- Hotel reservations and additional services
- Reservation status management
- PDF invoice generation
- Administration of guests, employees, rooms, services and countries
- Pagination and global search

## Tech Stack

**Backend:** Java, Spring Boot, Spring Security, Spring Data JPA, Hibernate  
**Frontend:** React, Vite, Tailwind CSS  
**Database:** MySQL  
**Other:** JWT, BCrypt, Spring Mail, OpenPDF

## About

The project was developed as part of the Advanced Java Technologies course at the Faculty of Organizational Sciences.
